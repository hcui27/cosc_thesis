Welcome to the .ng Domain Registry website.

NiRA is the registry for .ng Internet Domain Names and maintains the database of names registered in the .ng country code Top Level Domain.

NiRA is a Not-for-Profit, Non-Governmental Self-Regulating body and manager of the .ng national resource, the country code Top Level Domain (ccTLD) name space, in the public interest of Nigeria and global internet communities.
